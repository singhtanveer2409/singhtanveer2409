## Featured project

### [Sensor Anomaly Detection](https://github.com/singhtanveer2409/Anamoly-Detection)

![Python](https://img.shields.io/badge/Python-3670A0?style=flat-square&logo=python&logoColor=ffdd54)
![LightGBM](https://img.shields.io/badge/LightGBM-02569B?style=flat-square)
![XGBoost](https://img.shields.io/badge/XGBoost-EC6B23?style=flat-square)
![Scikit-learn](https://img.shields.io/badge/scikit--learn-F7931E?style=flat-square&logo=scikitlearn&logoColor=white)
![Pandas](https://img.shields.io/badge/Pandas-150458?style=flat-square&logo=pandas&logoColor=white)

Detects anomalous readings in industrial sensor data. Placed 6th in a Kaggle competition.

- Data: about 1.64M training rows, five sensor channels, only ~0.86% anomalies, with drift over four years.
- Two sensors turned out to be exponentiated log-counts. Reversing that raised their correlation with anomalies from roughly 0.03 to 0.35, the biggest gain of the project.
- Compared logistic regression, decision trees, KNN, SVM, random forest, XGBoost, LightGBM and neural nets. LightGBM with a tuned threshold (0.91) worked best.
- Anomaly-class F1 of 0.806 on validation; leaderboard score 0.828 public, 0.813 private.
