###### 02 / SELECTED WORK

## [Sensor Anomaly Detection](https://github.com/singhtanveer2409/Anamoly-Detection)

<sub>PYTHON &nbsp;·&nbsp; LIGHTGBM &nbsp;·&nbsp; XGBOOST &nbsp;·&nbsp; SCIKIT-LEARN &nbsp;·&nbsp; PANDAS</sub>

Detects anomalous readings in industrial sensor data. Placed 6th in a Kaggle competition.

- **Data:** about 1.64M training rows, five sensor channels, only ~0.86% anomalies, with drift over four years.
- **Key finding:** two sensors turned out to be exponentiated log-counts. Reversing that raised their correlation with anomalies from roughly 0.03 to 0.35, the biggest gain of the project.
- **Models:** compared logistic regression, decision trees, KNN, SVM, random forest, XGBoost, LightGBM and neural nets. LightGBM with a tuned threshold (0.91) worked best.
- **Results:** anomaly-class F1 of 0.806 on validation; leaderboard score 0.828 public, 0.813 private.

[View the repository](https://github.com/singhtanveer2409/Anamoly-Detection)
